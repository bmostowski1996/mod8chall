# Garage

This is a project which permits the creation and operation of vehicles using the terminal.

## Overview

The code supports the creation of three vehicle types:
1. Cars
2. Trucks
3. Motorbikes

Newly created vehicles are assigned a randomly generated VIN, and with each vehicle, you can perform any of the following actions:
- Print vehicle details
- Operate the vehicle --- Start/stop, accelerate/decelerate, turn left/right
- Tow (Trucks only)
- Wheelie (Motorbikes only)

For more information, see the video titled 'demo.mp4' in this repo.

## Running The Code
Navigate to the dist folder in the terminal and type `node index.js` to operate the code.
